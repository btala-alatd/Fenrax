# Fenrax

Private merch studio. Printify-ready graphics for Men, Women, and Kids shops.

## Render (phone or computer)

1. Open [render.com](https://render.com) → New+ → Blueprint
2. Connect GitHub and pick **btala-alatd/Fenrax**
3. When asked, paste your `GEMINI_API_KEY` (from Google AI Studio)
4. Wait for the first deploy (a few minutes)
5. Open the live URL in **Chrome** on the Flip 7 → menu → **Add to Home screen**

Do not commit API keys. Put them in Render env or in the in-app Settings screen.
